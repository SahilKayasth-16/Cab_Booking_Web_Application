# Cab Booking App

Full-stack ride-hailing app (Next.js, Express, Supabase, Stripe).

## Structure
- client: Next.js frontend
- server: Express backend

## Setup
1. `npm install`
2. Copy `server/.env.example` to `server/.env` and fill in the values
3. Copy `client/.env.example` to `client/.env.local`
4. `npm run dev`
